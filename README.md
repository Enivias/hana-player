# Hana Player 🌸

Windows · macOS · Android 에서 동작하는 캐릭터 뮤직플레이어 (Flutter, 코드 한 벌).

## 기능
**재생**
- 로컬 음악(mp3 m4a aac wav flac ogg opus) + **유튜브 링크(소리만)**, 앱 자체 볼륨, 재생 속도(0.75x~2x)
- 재생 모드: 순서대로 / 전체 반복 / 한 곡 반복 / 한 곡만 재생 + 셔플
- **이어 듣기**: 껐다 켜도 마지막 곡·위치에서 이어서 (재생 버튼을 누르면 시작)
- **슬립 타이머**: 15/30/45/60/90분 또는 "이번 곡이 끝나면", 마지막 20초는 볼륨이 서서히 줄어듦

**목록 관리**
- 플레이리스트 여러 개, 드래그로 순서 변경, 제목/아티스트순 정렬, 섞기, 검색
- ♥ **즐겨찾기** · 🕘 **최근 재생** 자동 목록
- 곡마다 이모지 스티커, 앨범 커버 수동 지정(내장 커버 없을 때), 가사 파일 연결
- 플레이리스트 **내보내기/가져오기**(.enivia.json)
- 파일/폴더를 창에 **드래그 앤 드롭**, 유튜브 링크는 **Ctrl+V** 로 바로 추가

**가사**
- 🎤 `Ctrl+L`: 싱크 가사는 현재 줄이 따라오고, 줄을 누르면 그 위치로 이동
- 찾는 순서: 저장해 둔 가사 → 같은 이름의 `.lrc` → 파일 태그 → 온라인(lrclib.net, 설정에서 끌 수 있음)

**귀여움 + 편의 (v5)**
- 🔔 **귀여운 버튼음** 5종(뽁뽁·딸랑·보글·8비트·말랑)과 끄기, 크기 조절 — 재생/일시정지/이전/다음/♥/셔플·반복/추가할 때 소리가 나요. 설정(🎨 버튼)에서 고르면 바로 미리듣기. 소리를 바꾸고 싶으면 `tools/gen_sfx.py` 를 고쳐서 다시 실행
- 🌫️ **곡 사이 부드러운 전환**: 곡 끝에서 소리가 서서히 줄고 다음 곡 처음에서 서서히 커져요 (끄기/2/4/6/8초). 소리가 겹치는 크로스페이드는 아님
- 😊 **캐릭터 표정**: 재생 중 기분좋음 ♪, 곡 바뀜/눌렀을 때/♥ 신남 ✨, 멈춘 지 15초 뒤 졸음 💤(고개 갸웃). `assets/images/expressions/` 에 표정 이미지를 넣으면 그 이미지로 바뀜 (없으면 기본 이미지 + 이모지 이펙트)
- 🕘 **시간대 인사**, 1시간 넘게 들으면 "물 한 잔 마실까요? 💧"
- 📊 **청취 기록**(상단 📊): 이번 달/전체 청취 시간, 최근 7일 그래프, 많이 들은 곡 TOP 10·아티스트 TOP 5
- 🆕 **최근 추가**, 🙈 **안 들은 곡** 자동 목록 (♥ 즐겨찾기·🕘 최근 재생과 함께)

**귀여운 UI**
- 캐릭터가 재생 중 통통 튀고, 곡이 바뀌거나 멈추면 말풍선으로 한마디, 캐릭터를 누르면 깡충
- 꽃잎 애니메이션, 이퀄라이저 막대, 긴 제목 흐르기, 8가지 테마색 × 라이트/다크/시스템

**Windows 데스크톱**
- 커스텀 타이틀바, 항상 위, **미니 플레이어**, **캐릭터 위젯**(300×420, 마우스를 올리면 컨트롤, 더블클릭으로 복귀)
- **미디어 키**(⏯ ⏭ ⏮ ⏹)와 전역 단축키 `Ctrl+Alt+Space / ← / →` — 다른 창을 보고 있어도 동작
- **시스템 트레이**(클릭=열기, 우클릭=재생/이전/다음/종료), 설정에서 "닫기(X)=트레이로" 선택
- 작업표시줄 미리보기/Alt+Tab 에 지금 곡 제목 표시
- 단축키: Space 재생/정지, Ctrl(⌘)+←/→ 이전/다음, Ctrl+V 링크 붙여넣기, Ctrl+L 가사

## 시작하기
1. [Flutter SDK](https://docs.flutter.dev/get-started/install) 설치 (3.19 이상 권장)
   - Windows 빌드: Visual Studio 의 "C++를 사용한 데스크톱 개발"
   - macOS 빌드: Xcode
   - Android 빌드: Android Studio
2. 이 폴더에서 설정 스크립트 실행
   - macOS: `bash setup.sh`
   - Windows: `setup.bat`
3. 실행
   ```
   flutter run -d windows
   flutter run -d macos
   flutter run -d <안드로이드 기기 ID>
   ```
4. 배포용 빌드
   ```
   flutter build windows
   flutter build macos
   flutter build apk        # 또는 appbundle
   ```
※ macOS 빌드는 Mac 에서, Windows 빌드는 Windows 에서만 가능합니다.

## 캐릭터 이미지
`assets/images/` 에 있습니다. 같은 파일명으로 바꾸면 앱에 바로 반영돼요.
- `character.png` : 중앙 캐릭터 (가장자리를 부드럽게 처리한 PNG)
- `backdrop.jpg` : 흐린 배경
- `assets/icon/app_icon.png` : 앱 아이콘 (얼굴 부분)

앱 이름은 `lib/main.dart` 의 `appTitle` 한 곳만 바꾸면 됩니다.

## 아직 안 넣은 것
- Android 알림창/잠금화면 컨트롤, Windows 볼륨 오버레이(SMTC)·작업표시줄 썸네일 버튼, 이퀄라이저(Windows 재생 엔진 한계) — 필요하면 다음 단계로
- 캐릭터 표정 변화: 지금은 이미지 1장이라 말풍선+동작으로 반응해요. 표정 이미지를 `assets/images/` 에 더하면 연결할 수 있어요

## 참고
- 유튜브 재생은 비공식 방식(`youtube_explode_dart`)이라 유튜브 이용약관상 회색지대이고, 유튜브 쪽 변경으로 갑자기 안 될 수 있어요(그럴 땐 패키지 업데이트). 개인 용도로만 쓰세요. 연령 제한/비공개/지역 제한 영상은 재생되지 않을 수 있어요.
- 이 프로젝트는 Flutter 가 없는 환경에서 작성되어 아직 빌드해 보지 못했습니다. 첫 빌드에서 패키지 버전 차이로 작은 수정이 필요할 수 있어요.
- Android 는 선택한 음악을 앱 전용 폴더로 복사해 둡니다(캐시가 비워져도 목록이 깨지지 않게).
- Windows 는 `just_audio_media_kit`, macOS/Android 는 just_audio 기본 엔진을 씁니다.
- Android 는 파일 선택기(SAF)를 사용하므로 별도 저장소 권한이 필요 없습니다.
- macOS 샌드박스에서 파일을 읽기 위해 `setup.sh` 가 `user-selected.read-only` 권한을 추가합니다.
- ogg/opus 같은 형식은 플랫폼 기본 엔진에 따라 macOS 에서 재생이 안 될 수 있습니다.

## 채팅 (VChatCloud)
- 상단 💬 버튼 → 같은 채널키를 쓰는 사용자끼리 실시간 채팅. 처음 열 때 접속하고, 닉네임은 자동 생성돼요 (✏️ 로 변경).
- 🎵 버튼으로 지금 듣는 곡을 채팅방에 공유할 수 있어요.
- 채팅방은 하나로 고정되어 있어요. 채널키는 화면에 표시되지 않고 바꿀 수 없어요 (코드의 `defaultChatKey`).
- 주의: vchatcloud_flutter_sdk 가 http 0.13 을 요구해서 pubspec 의 dependency_overrides 로 http 1.x 로 통일했어요.

## 구글 로그인 (채팅 닉네임)
- 채팅창 ✏️ → 🔐 구글 계정 → 구글로 로그인. 브라우저가 열리고 로그인하면 앱으로 돌아와요.
- 로그인하면 닉네임이 구글 계정에 설정된 이름으로 자동 설정되고(12자까지, 이름이 없으면 이메일 앞부분), 언제든 직접 바꿀 수 있어요.
- 앱은 비밀번호나 토큰을 저장하지 않고, 계정 고유값·이메일·이름만 저장해요.
- 구글 클라우드 콘솔의 OAuth 클라이언트가 **"데스크톱 앱"** 유형이어야 해요. 로그인 시 "client_secret is missing" 같은 오류가 나면 같은 화면의 '보안 비밀' 칸에 콘솔의 값을 넣어 주세요.
- 닉네임이 채팅방의 다른 사람에게 보이므로, 실명이 보이기 싫으면 닉네임을 직접 바꾸세요. 이메일은 채팅방에 보내지 않아요.
- 채팅창 상단 👥 숫자를 누르면 접속자 목록이 보여요. SDK 에서 전체 목록을 받아오는 기능을 찾지 못해서, 내가 들어온 뒤 입장했거나 말한 사람 기준으로 보여줘요.

## v9 추가 기능
- **채팅 곡 공유 → 바로 재생**: 유튜브 곡을 🎵 로 공유하면 링크가 함께 올라가고, 받은 사람은 ▶ 바로 듣기 / 🧾 대기열 / ➕ 내 목록에 버튼을 눌러요. 로컬 파일 곡은 🔍 유튜브에서 찾기 버튼이 떠요. 채팅에 붙여 넣은 유튜브 링크에도 같은 버튼이 나와요.
- **채팅 새 글 알림**: 채팅창이 닫혀 있으면 캐릭터가 말풍선으로 알려 주고, 💬 아이콘에 안 읽은 수가 표시돼요. 채팅 설정(✏️)에서 알림/자동 접속을 켜고 끌 수 있어요 (자동 접속은 기본 꺼짐).
- **재생 대기열**: 곡 ⋮ 메뉴 → ⏭ 다음에 재생 / 🧾 대기열 끝에 추가. 재생 화면의 🧾 대기열 버튼에서 끌어서 순서 변경·삭제. 대기열이 끝나면 원래 듣던 목록의 다음 곡으로 돌아가요. (앱을 끄면 대기열은 사라져요)
- **자동 목록 2개**: 🔥 자주 들은 곡(전체 TOP 30), 📅 이번 주 TOP(최근 7일 TOP 30). 곡을 30초 이상 들어야 기록돼요.

## 전체 검색
- 상단 🔍 또는 **Ctrl+K**(macOS 는 ⌘K): 모든 플레이리스트에서 곡·아티스트를 한 번에 찾아요.
- 단어를 띄어 쓰면 모두 포함된 곡만, **초성만 입력해도**(예: ㅂㅊ) 찾아요. Enter 로 첫 결과를 바로 재생해요.
- 결과에는 곡이 들어 있는 목록 이름이 같이 보이고, ⋮ 에서 다음에 재생 / 대기열 / 목록으로 이동을 고를 수 있어요.

## 메인 화면 이미지 바꾸기
- 🎨 설정 → 🖼️ 메인 화면 이미지 → 이미지 선택: 캐릭터 자리에 내가 고른 그림/사진이 나와요. (png, jpg 등)
- **전체 보이게**: 그림 전체를 모서리를 둥글게 해서 보여주고, 빈 곳은 같은 그림을 흐리게 깔아요. **꽉 채우기**: 무대를 가득 채워요(가장자리는 잘릴 수 있어요).
- '기본 캐릭터로'를 누르면 원래대로 돌아가요. 캐릭터 위젯 모드에도 같이 적용돼요.
- 내 이미지를 쓰는 동안에는 표정 이미지(expressions)는 쓰이지 않고, 통통 튀는 움직임·말풍선·이펙트는 그대로예요.

## 유튜브 검색 → 바로 등록
- 검색 창(🔍 / Ctrl+K)에서 **유튜브** 탭을 고르거나, 플레이리스트 위쪽 ▶ 아이콘(또는 **Ctrl+Shift+K**)으로 바로 열 수 있어요.
- 곡 이름·아티스트를 입력하고 Enter → 결과(썸네일·제목·채널·길이)가 나와요.
  - 줄을 누르면 목록에 넣지 않고 바로 들어 볼 수 있어요.
  - ➕ 는 선택한 '추가할 목록'에 등록, 🧾 는 대기열에 추가, '결과 N곡 모두 추가'로 한꺼번에 등록할 수 있어요.
- 유튜브 뮤직 전용 카탈로그가 아니라 일반 유튜브 검색 결과예요. 소리만 재생하며, 개인용으로만 쓰세요 (유튜브 약관상 회색 영역).

## v16 — Windows 데스크톱 기능
- **중복 실행 방지** (`services/instance_service.dart`): 첫 실행이 내 컴퓨터 안(127.0.0.1:47931)에서만 열리는 문을 연다. 또 실행하면 새 창 대신 켜진 창이 앞으로 나오고, 열려던 파일은 그 창에서 재생된다. 포트를 다른 프로그램이 쓰고 있으면 막지 않고 그냥 실행한다.
- **파일 연결** (`services/file_assoc_service.dart`): 설정 > 🖥 윈도우 기능 > 연결 등록. 관리자 권한 없이 현재 사용자 레지스트리(HKCU)에만 기록하며, 해제하면 지워진다. 윈도우 정책상 앱이 '기본 앱'을 직접 바꿀 수 없으므로 우클릭 > 연결 프로그램 에서 고르거나 기본 앱 설정에서 한 번 지정한다. 더블클릭으로 열린 파일은 시작 인자로 받아 바로 재생한다.
- **작업표시줄 컨트롤** (`services/taskbar_service.dart`, `windows_taskbar`): 작업표시줄 아이콘 미리보기 아래에 ⏮ ⏯ ⏭ 버튼. 아이콘은 `assets/taskbar/*.ico`.
- **방향키**: ← 5초 뒤로, → 5초 앞으로 (곡 범위 안으로 제한), Space 재생/일시정지(전부터 있음), F1 도움말. 입력창에 글자를 치는 중에는 입력창이 먼저 키를 받는다.
- **폴더 자동 감시** (`services/folder_watch_service.dart`): 설정 > 🖥 윈도우 기능 > 폴더 추가. 하위 폴더 포함, 새 음악은 「📁 감시 폴더」 목록에 실시간 추가, 지운 파일은 목록에서 제거(드라이브가 빠져 있을 때는 지우지 않음). 복사 중인 파일은 끝날 때까지 기다리고, 알림을 놓칠 때를 대비해 60초마다 한 번 더 비교한다.
- **앨범 · 아티스트별 보기**: 상단 📚 버튼. 곡마다 파일 태그의 앨범을 저장하고(옛 곡은 열 때 한 번 채움), 묶음째 ▶ 재생하거나 곡을 눌러 그 곡부터 재생한다. 재생 목록은 「🎧 앨범·아티스트 재생」에 담긴다.
- **도움말 탭**: 상단 ❓ 버튼 또는 F1. 단축키·전역 키·기능 안내.
- **출력 장치**: 앱 안에서 장치를 직접 고르는 기능은 지금 재생 엔진(just_audio_media_kit)이 장치 선택을 지원하지 않아 넣지 못했다. 대신 설정 > 🖥 윈도우 기능에서 윈도우의 「앱별 볼륨 및 장치 기본 설정」을 열어 Hana Player 만 다른 장치로 보낼 수 있다. 앱 안 선택이 꼭 필요하면 재생 엔진을 media_kit 으로 직접 바꾸는 큰 작업이 필요하다.
- 아직 컴파일/실행해 보지 못했다. 처음 빌드에서 오류가 나면 `🧰 도구 > 문제 보내기` 또는 빌드 오류 문구를 알려 주세요.
